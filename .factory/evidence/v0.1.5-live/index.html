How it works

Search without combining vaults

  1. 01

    Choose local vaults

    Add .kdbx files explicitly. Each stays where you put it.

  2. 02

    Unlock for this session

    Your master password goes to the local app and is cleared after use.

  3. 03

    Search metadata

    Search titles, usernames, URLs, and group paths. Passwords and notes are excluded.

  4. 04

    Open the owning vault

    Open the original database in your associated password app.

Privacy

Metadata stays in the local session.

The desktop index exists only in process memory. Lock a vault, lock all vaults, quit, or let the timer run out to clear it.

  • No analytics or telemetry
  • The desktop app never copies secret values
  • No password storage or autofill
  • No background sync
