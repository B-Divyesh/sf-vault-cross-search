Designed around the threat model

An index that knows when to disappear.

The index exists only in process memory. Lock one vault, lock all vaults, quit the app, or let the timer run out: searchable metadata is zeroed and removed.

  • No analytics or telemetry
  • No clipboard writes
  • No password storage or autofill
  • No background sync
