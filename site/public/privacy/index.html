Privacy

Effective 1 September 2026

Vault Cross Search is designed not to collect your data. The desktop app has no analytics, telemetry, advertising, or crash reporting.

Local vault processing

Vault files and unlock credentials are processed locally on your device. The app indexes only title, username, URL, and group path in process memory.

It does not index passwords, notes, attachments, or custom protected fields. Locking, quitting, or the inactivity timeout clears the index.

License verification

If you restore a license, the app sends its token to the Sociobot billing API. The app stores the verification result and time locally.

License purchases are not available while checkout registration is pending.

Website and demo

The website loads no third-party scripts, fonts, trackers, or advertising. The demo uses bundled records and separate browser storage.

The desktop app never copies secret values. Website install buttons copy only their visible public install commands after you press Copy.

Choosing “Download the desktop app” asks GitHub for the latest release asset. It does not send vault data.

Standard server logs may contain your IP address and user agent for short-term security and reliability work.

Your control

Use “Lock all” to clear the current index. You can remove the license from your operating system’s webview data.

Questions: privacy@sociobot.in.
